# Breast Cancer Classification 

Dieses Projekt demonstriert die Anwendung von Machine Learning Methoden auf medizinische Datensätze. Als Biologin (M.Sc.) kombiniere ich hier mein Fachwissen über zelluläre Merkmale mit moderner Datenanalyse, um die Klassifizierung von Tumorgewebe zu automatisieren.

## 📌 Projekt-Überblick
Das Ziel dieses Projekts ist es, einen Datensatz von Zellkern-Merkmalen zu analysieren und ein Modell zu trainieren, das zwischen **malignen** (bösartigen) und **benignen** (gutartigen) Tumoren unterscheidet.

## 🛠️ Tech-Stack
* **Sprache:** Python
* **Bibliotheken:** Pandas, NumPy (Datenverarbeitung)
* **Visualisierung:** Matplotlib, Seaborn (Explorative Datenanalyse)
* **Machine Learning:** Scikit-Learn (Random Forest Classifier)

## 📊 Ergebnisse
Das Modell erreicht eine hervorragende Performance auf dem Test-Datensatz:
* **Accuracy:** 97%
* **Recall (Klasse 0 - Maligne):** 94% – Dies ist besonders wichtig, um sicherzustellen, dass bösartige Tumore nicht übersehen werden.
* **F1-Score:** 0.96

### Confusion Matrix & Performance
Im Notebook enthalten sind Visualisierungen der **Confusion Matrix** zur Fehlersuche sowie eine **Heatmap**, um Korrelationen zwischen Zellmerkmalen wie Radius, Textur und Symmetrie aufzuzeigen.

## 🚀 Key Takeaways für Data Science
* **Feature Understanding:** Nutzung von Domänenwissen zur Interpretation biologischer Merkmale.
* **Modell-Evaluation:** Fokus auf den Recall zur Minimierung von False Negatives in einem medizinischen Kontext.
* **Datenvisualisierung:** Aufbereitung komplexer Metriken für eine klare Entscheidungsfindung.
